# display_mount — タッチディスプレイの取付部品

ケース付きのWaveshareのディスプレイ（外形 254 × 187 × 26.1 mm、表示部 217.9 × 136.6 mm）を、
頭の下、2本の昇降レールの前に固定する3Dプリント部品。どれもBambu Lab A1 mini（180 mm角）で印刷できる。
フレーム上部の梁の下面から印刷した背骨を吊り、その前面にケースの受けと押さえを付ける。

| 部品 | 取付 |
| --- | --- |
| `01_frame_adapter` | 梁の下面にM6 × 4、背骨の背面にM5 × 2。頭のパンサーボの可動範囲の後ろを回って背骨へつなぐ |
| `05_spine` | 背骨（40 × 174 × 20 mm）。M5のナットを六角穴に入れる |
| `02_lower_left` / `03_lower_right` | 背骨の前面に左右並べて、それぞれM5 × 2。ケースの下の角を受ける（左右は正面から見た向き） |
| `04_top_keeper` | 背骨の前面にM5 × 2。ケースの上面を1 mmのすき間で押さえる。結束バンド用の穴が2つある |

M5のボルトは25 mm（長いと押さえに当たる）。受けと押さえの穴は上下±2 mmの長穴。
ケース背面の下側中央（幅140 × 高さ40 × 奥行40 mm）は、コネクタとケーブルのために空けてある。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `0*_*.stl` | 印刷用（mm）。`01_frame_adapter` は梁に当たる面をベッド面に向けてある |
| `0*_*.step` | 部品ごとのSTEP |
| `display_mount_assembly.step` | 組立。ケースと表示部の外形を含む |
| `display_mount_assembly.f3d` | Fusionのアーカイブ |
| `fusion/build_display_mount.py` | Fusionのscript。新しいドキュメントに部品を作り、このディレクトリへSTEP・STL・f3dを書き出す |

組立とscriptの座標は上流の [Astra.STEP](../../../../../upstream/Astra_Hardwares/Astra/Astra.STEP) と同じ
（+X ロボットの左、+Y 上、+Z 前、mm）。ケースはX ±127、Y 1000〜1187、Z 560〜586.1、
背骨はX ±20、Y 1058〜1232、Z 490〜510。

## URDF

[display.xacro](../../urdf/display.xacro) が `base_link` に固定した `display_link`（ケース前面の中央、x が画面の外向き、z が上）を加える。
ケースは箱、印刷部品はビルド時に [display_mount_mesh.py](../../scripts/display_mount_mesh.py) がこのディレクトリのSTLから作る1つのメッシュで表し、見た目と衝突判定に使う。
質量は実測がないため入れていない。

STEPの座標から `base_link`（m）へは、x = (Z − 495.268) / 1000、y = X / 1000、z = (Y + 147) / 1000。
頭のパン・チルト軸（STEPのX 0、Y 1282、Z 545.268）と、梁の下面（Y 1341）が上流のURDFに一致する値。
部品の形や位置を変えたときは、STLを書き出し直し、`display_mount_mesh.py` の部品の原点と `display.xacro` の寸法を合わせる。

## 腕との干渉

ディスプレイは昇降する腕の高さにあり、腕を体の前へ回したまま昇降0.9 m以上へ上げると当たる。
MoveItの計画は避けるが、操作パネルからの昇降などMoveItを通らない指令では防げない。
