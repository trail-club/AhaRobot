添付のWireViz YAML（.yml）を読み取り、機器の外観と各端子への配線が直感的に分かる「機器配置型の配線図」を作成してください。
【配線情報の扱い】
- 電気的な接続は、添付YAMLを唯一の正本としてください。connectors、cables、connections、loops、および関連するnotesを読み取り、全接続を忠実に反映してください。
- 接続先、端子名、極性、配線色、未接続端子を省略・変更しないでください。
- 同じ機器の端子群が複数のconnectorに分かれている場合は、一つの機器として描き、その中に各端子群を配置してください。
- YAMLの論理端子番号と実機の物理ピン番号を区別してください。論理番号を、実機のピン位置や端子番号として扱わないでください。
- YAMLにない部品・配線・USB接続・保護回路などを追加しないでください。不明な仕様は推測で補完しないでください。
【機器の描き方】
- 単純な箱だけのブロック図ではなく、基板、モータドライバ、モータ、センサ、電源などを識別できる、簡潔なベクターイラストにしてください。
- 写真のような写実性より、端子と配線の読みやすさを優先してください。
- 各機器には機器名・型番、各端子には端子名を記載してください。
- 実際の端子配置が確認できない場合は、分かりやすい模式配置にしてください。外観の細部や端子位置を実機仕様として捏造しないでください。
【配線の描き方】
- 各導線を接続元の端子から接続先の端子まで連続して描き、どこにつながるか一意に追えるようにしてください。
- 配線色はYAMLに従ってください。同色線は配線IDや信号名で識別できるようにしてください。色未指定の線は中立色で描き、色指定があるように見せないでください。
- 配線は水平・垂直を中心に整理し、交差を最小限にしてください。
- 電気的な接続点には接続ドットを付け、接続しない交差は線のジャンプなどで明確に区別してください。
- 配線を機器内部や文字の上に通さないでください。
- 未使用端子と未接続の導線端は、短いラベルや絶縁端の表現で示してください。センサの「NC接点」と「未接続」を混同しないでください。
- 白や黄色などの薄い配線も白背景で判別できるよう、細い縁取りなどで調整してください。
【レイアウトと省略する要素】
- 白背景で、機器と配線を中心とした一枚の図にしてください。
- 図には機器・端子・配線と、それらを識別するために必要なラベルのみを配置してください。図の周囲に見出しや説明文、注記などの文章を追加しないでください。
- 下部の説明文、注意事項、出典、フッター、ページ番号も不要です。
- 配線表やBOMは掲載しないでください。
- 残す文字は、機器名・型番・端子名・配線ID・信号名・電圧・未接続表示など、接続を理解するために必要なものに絞ってください。
- 機器の配置と向きを調整し、文字の重なりや大きな空白がない、読みやすい構図にしてください。
【作成と検証】
- SVGなど、端子・配線・文字の位置を正確に制御できる方法で作成してください。
- 完成後に、YAMLの全接続と図の端子間接続を照合し、配線の欠落・追加・接続先の取り違えがないことを確認してください。loopsによる内部接続と未接続線も確認対象にしてください。
- 実際に画像として描画し、文字の重なり、配線の追いやすさ、接続点と交差の区別を目視確認してから完成させてください。
完成した図を表示し、編集・拡大可能なSVGと高解像度PNGを提供してください。
