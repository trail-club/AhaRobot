# 物体検出（SAM 3.1）の測定・検証記録

商品名で指定した物だけを SAM 3.1 で見つける方式の、実機写真での比較を日付順に記録する。
使い方は [SAM 3.1＋DINOv2](../../tools/perception/macos/sam31_dinov2/README.md)・[SAM 3.1 検証ツール](../../tools/perception/macos/sam31/README.md)、
各方式の流れと代表画像は [方式の比較ページ](../../tools/perception/macos/sam31_dinov2/index.html)、
正解の枠は `tools/perception/macos/sam31_dinov2/data/`、各方式の結果は同じディレクトリの `results/` にある。

共通の条件：

- 写真は頭部カメラ（D435i）を Mac につないで `interactive.sh` で撮った RGB-D。
- SAM 3.1 と VLM は DGX Spark で動かした。VLM は 2026-10-18 までの記録が Qwen3-VL（`qwen3-vl:30b`、Ollama）、2026-10-25 からは Qwen3.8（`qwen3.8-27b`、[ローカルLLM](../../tools/local-llm/README.md)）。
- 正解の枠と IoU が 0.5 を超えれば「見つけた」とし、写真は「対象を全部見つけて、誤りがない」ときに正解とした。50画素未満のマスクは数えない。
- 時間は DGX での処理時間で、写真の転送とモデルの読み込みは含まない。

## 2026-10-11 — SAM 3.1 単体での商品名

### 観測結果

- プリングルズ・キャンベル缶・除菌シートが写った写真で、言葉「pringles」を渡すと、プリングルズが 0.84、キャンベル缶が 0.74 になった。

### 解釈と確認していない範囲

SAM 3.1 は見た目の種類で物を拾い、商品名は区別しないと考えられる。商品名の物だけを残す仕組みが別に必要と判断した。

## 2026-10-13 — 案A・案B（プリングルズなど14枚、19回）

### 対象・条件

2026-10-11 に撮った14枚の写真に対して、言葉を変えて19回実行した。対象はプリングルズ（裏向きを含む）など。

- **案A**：Qwen が言葉を英語に言い換える → SAM 3.1 で候補を出す（しきい値 0.3） → Qwen が対象を選ぶ。
  照合ありの場合は、選ばれなかった候補を選ばれた物と並べ、Qwen に同じ商品かを聞く。並べるときは深度で実寸をそろえ、cm の大きさも伝える。
- **案B**：Qwen が対象の枠を描き、SAM 3.1 に渡す。
  - B1：枠だけを渡す。
  - B2：枠と形の言葉を渡し、さらに照合する。言葉が商品名のままの場合は、(a)「container」を使うか、(b) 枠の中だけを見せて聞き直す。

### 観測結果

| 方式 | 正解した写真 | 見つけた / 誤り / 見逃し | 1回の時間（平均・最長） |
| --- | --- | --- | --- |
| 案A 選択のみ | 17 / 19 | 22 / 0 / 2 | 31.3 秒・107.3 秒 |
| 案A 選択＋照合 | 19 / 19 | 24 / 0 / 0 | 31.3 秒・107.3 秒 |
| 案B1 枠だけ | 17 / 19 | 22 / 0 / 2 | 3.7 秒・11.6 秒 |
| 案B2（a） | 19 / 19 | 24 / 0 / 0 | 16.3 秒・41.6 秒 |
| 案B2（b） | 19 / 19 | 24 / 0 / 0 | 15.5 秒・43.3 秒 |

- 見逃しは、どちらも裏向きのプリングルズだった。照合を加えると見つかった。
- 照合で実寸をそろえる前（同じ高さに並べた場合）は、キャンベル缶まで「同じ」と判断され、14/19 だった。

### 解釈と確認していない範囲

裏向きを含めて正解するには照合が必要だった。案Aは時間の大半が Qwen の思考出力にかかる。
裏向きの例は同じ写真の2回だけで、裏向きしか写っていない写真は試していない。
案Aは `interactive.sh --vlm` として実装した。案Bは検証だけで、実装していない。

## 2026-10-18 — キャンベル缶27枚での方式比較と SAM 3.1＋DINOv2 の採用

### 対象・条件

プリングルズが手元になくなったので、対象をキャンベル トマトスープ缶に変えた。
写真は27枚：2026-10-11 の18枚（別の部屋。缶は正面・裏向き・横向き）と、2026-10-18 の9枚（コカ・コーラ缶やサッポロ缶と並べた写真、裏向き、2缶、隠れた缶、缶なしを含む）。
参照画像は `reference.sh --name campbell` で4方向（正面・背面・左右）を撮った。

- **案A**：言葉「campbell」で実行した（照合あり）。
- **参照を並べる**：写真の右に参照画像を並べ、参照の物の枠をお手本として SAM 3.1 に渡す。参照は正面だけか4方向で、言葉はなし・can・soup can・campbell's tomato soup を試した。
- **SAM 3.1＋DINOv2**：SAM 3.1 に「can」を渡して候補を出す（しきい値 0.3）。候補をマスクで切り出し、参照4方向とのコサイン類似度（DINOv2 の CLS 特徴）の最大値を点数にする。

しきい値は、それぞれの方式で27枚の結果が一番良くなる値を選んだ。

### 観測結果

| 方式 | 正解した写真 | 見つけた / 誤り / 見逃し | 1枚の時間（平均・最長） | しきい値 |
| --- | --- | --- | --- | --- |
| 案A | 19 / 27 | 24 / 5 / 4 | 28.3 秒・69.4 秒 | - |
| 参照を並べる（正面＋soup can、最良） | 8 / 27 | 23 / 21 / 5 | 0.41 秒・0.99 秒 | 0.88 |
| DINOv2 small | 17 / 27 | 17 / 0 / 11 | 0.37 秒・0.39 秒 | 0.73 |
| DINOv2 base | 19 / 27 | 25 / 10 / 3 | 0.37 秒・0.39 秒 | 0.65 |
| DINOv2 large | 23 / 27 | 25 / 1 / 3 | 0.39 秒・0.40 秒 | 0.52 |

- **案A**：照合でキャンベル缶の隣の缶を加えた写真が4枚、見逃した写真が3枚あった。
- **参照を並べる**：どの条件でも、コカ・コーラ缶やプリングルズの点数がキャンベル缶とほぼ同じになった。
- **DINOv2**
  - 部分の特徴を平均すると、CLS 特徴より結果が悪かった。
  - large のキャンベル缶の点数は、参照と同じ日の写真で 0.78〜0.95、別の部屋の写真で 0.47〜0.80、隠れた缶や端で切れた缶で 0.34〜0.55だった。ほかの物の点数は最高 0.61。
  - large でまちがえた4枚は、端で切れた缶、陰の細い部分、栄養成分表示の面を向けたプリングルズ（0.61 と 0.63）、点数差が 0.01 の写真（0.47 と 0.48）。
  - 1枚の中では、27枚中25枚でキャンベル缶が一番高い点数だった。

### 解釈と確認していない範囲

- 参照を並べる方式では、SAM 3.1 は参照画像を「この商品」ではなく「缶という種類」として扱うと考えられる。SAM 3 のお手本の枠は同じ画像の中でしか使えないとされている（facebookresearch/sam3 issue #426）。
- 正解数が最も多く、案Aより約70倍速いので、SAM 3.1＋DINOv2 large（しきい値 0.52）を採用した。
- しきい値は評価と同じ27枚で選んだので、正解数は甘めになっている。撮影場所が変わると点数が下がり、全写真に共通のしきい値で分けられる幅はない。
- 試した物はキャンベル缶だけで、ほかの物での点数は確認していない。案Bはこの27枚では試していない。

## 2026-10-18 — SAM 3.1 に渡す言葉の比較

### 対象・条件

利用者が名前だけで使えるようにするため、上の27枚と DINOv2 large で、SAM 3.1 に渡す言葉を5通り比べた。
Qwen が決める言葉は、参照画像（正面）の中央を Qwen に1回見せて決めた。結果は `cylindrical can` で、11.3 秒かかった。

### 観測結果

| 言葉 | キャンベル缶が候補に出た数 | 正解した写真 | 1枚の時間 |
| --- | --- | --- | --- |
| 人が決めた `can` | 28 / 28 | 23 / 27 | 0.39 秒 |
| 固有名詞 `campbell's tomato soup` | 24 / 28 | 21 / 27 | 0.38 秒 |
| `object` | 3 / 28 | 2 / 27 | 0.35 秒 |
| Qwen が決めた `cylindrical can` | 28 / 28 | 23 / 27 | 0.38 秒 |
| 種類の言葉7つをまとめる | 28 / 28 | 23 / 27 | 2.44 秒 |

正解した写真は、言葉ごとに27枚で一番良いしきい値で数えた。`object` では、参照画像を撮るときも4枚中0枚で物が出なかった。

### 解釈と確認していない範囲

DINOv2 は候補の中からしか選べないので、対象が候補に出る言葉が必要になる。
登録時に Qwen が言葉を1回決めて保存する方式を標準にし、言葉を自分で指定する方式（Qwen なし）も残した。
Qwen が決める言葉は缶でしか確かめておらず、実カメラで撮影しながら言葉を決める流れは確認していない。

## 2026-10-25 — VLM を Qwen3.8 に切り替えたときの思考の有無

### 対象・条件

VLM を Qwen3.8（画像入力を有効にしたローカルLLM）に切り替え、思考過程の出力の有無を比べた。
2026-10-13 からの19回の写真はこの Mac になく、19回の評価はやり直していない。比べたのは次の2枚。

- 方式比較ページの候補画像（`img/a_candidates.jpg`、斜線と番号を描いたもの、対象はプリングルズ＝候補1）。
  候補の選択では、元の写真の代わりにこの画像を2枚とも渡した。
- 2026-10-04 に撮った実カメラの写真1枚（`artifacts/perception/realsense-20261004/rgbd.npz`、白いボトル）。

時間は Mac から WARP 経由で送ってから回答を受けるまで。

### 観測結果

| 内容 | 思考あり | 思考なし |
| --- | --- | --- |
| 候補の選択（候補画像） | `[1, 2]`（2はキャンベル缶で誤り）、162.5 秒、思考 5992 トークン | `[1]`、1.5 秒 |
| 言い換えの句（実写真、`白いボトル`） | `white bottle` ほか2つ、4.3 秒 | 同じ3つ（順序違い）、1.5 秒 |
| 種類の言葉（実写真） | `plastic bottle`、8.1 秒 | `plastic bottle`、0.8 秒 |

思考ありで上限の 4096 トークンを使うと、候補の選択は思考だけで終わり、回答が空になった。
候補画像に言い換えの句を求めると、思考なしでは `yellow banana`・`yellow lemon` が返った（思考ありは `yellow snack box` など）。
ただし、実際の言い換えは斜線のない元の写真で行う。

### 解釈と確認していない範囲

思考なしを既定にした（`VlmClient(thinking=False)`）。比べたのは2枚だけで、19回・27枚の評価は Qwen3.8 で行っていない。
同じ商品かを比べる照合（`MATCH_PROMPT`）と、案B（Qwen が枠を返す方式）は Qwen3.8 で試していない。
