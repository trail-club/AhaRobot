# 置く動作の実機試行

骨組みに載せた実機（[骨組み](frame.md)）で、試験用の置く動作（`aha_test_manipulation` の `manip_real.launch.py` の `PlaceObject`）を試した記録を日付順に残す。
起動と設定は [aha_test_manipulation](../../tests/ros/aha_test_manipulation/README.md#実機骨組み) を参照。

## 2026-10-25 — 手前の机への試行

### 対象・条件

- 置く先：ロボットの前の机。平面検出の高さ0.346〜0.347 m、ラベル `other`。goalは `surface_labels: [other]`、`grasp: side`、`approach: side`。
- 物体：グリッパにユーザーが入れたバナナとカップ。カップは押し付けると右腕の基板がリセットされるため（[モーター](motor.md)）、幅を指定して押さえない位置まで閉じた（指が止まった開きは片側0.021〜0.026 m）。
- 頭のサーボは使わず（`aim_head:=false`）、tiltはD435iのIMUから求めた。ユーザーが机に障害物（高さ約18 cmと22 cmの物など）を置いた試行がある。
- 手先の高さ（`tcp_height`）は、試行1〜5が校正前のモデル（右0.452 m、左0.474 m）、試行6・7が点群で校正した後のモデル（右0.432 m、[骨組み](frame.md)）。
- 試行ごとに設定を直した。試行1〜5は `velocity_scaling` 0.5、`verify_detections` 1、`placed_padding` 0。試行7は `velocity_scaling` 0.3。

- 試行1・3・6の後、腕は戻りの姿勢（carry）に戻った。試行7の戻りはOMPLの計画（計画2.3 s、実行11.6 s）で、途中で手が傾いた。
- カップの箱の中心は、離した位置よりロボット寄りに3〜4 cmだった。

### 決定事項と根拠

- 止まった腕の読みは全桁同じになるため（試行0）、読みの停止は軌道の実行中に指令が動いているときだけで判定する（試験用の place_server の `frozen_window`。軌道ブリッジは変えない）。
- 加速度による拒否（試行5・6）から、MoveItの加速度の上限をブリッジの半分、実機の `velocity_scaling` を0.3にした。
- 試行7から、置いた後の確認を最大3回の検出で行い（`verify_detections`）、置いた物の箱を各方向に3 cm広げて戻りの経路を計画する（`placed_padding`）ようにした。

### 確認していない範囲

上の決定による設定（`velocity_scaling` 0.3以外）と、校正後のモデルで高さ0.12 mの物体を置く場合は試していない（0.346 mの机に置けるのは、0.432 mの手先で高さ約6〜10 cmの物体）。
試行7で手が当たった位置と、カップの位置のずれの原因（箱の中心の偏り、腕の校正の残り）は分けていない。
試行4・5の左腕の取り付けの向きは校正していない。
