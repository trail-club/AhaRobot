# 骨組みの測定記録

台車と昇降のない実機（机の上の骨組みに腕と頭を載せた構成）の寸法を日付順に記録する。
モデルの書き方は [aha_bringup](../../overlay_ws/src/aha_bringup/README.md#real-robot-on-the-frame) を参照。

## 2026-10-25 — 骨組みの寸法と構成

### 対象・条件

高さ38 cmの机に、30 mm系のアルミフレームの骨組みを置き、その上に左右の腕（Astraの腕）と頭（AstraのHeadYaw・panサーボ・tiltブラケットとD435i用ブラケット）を取り付けた構成。
寸法はユーザーがメジャーで測り、構成は写真3枚（正面・真上・左の真横）と口頭の説明による。

### 測った値

| 対象 | 値 |
| --- | --- |
| 床から机の天板 | 38 cm |
| カメラの柱（30×30を2本左右に並べたもの）、天板から上端 | 50 cm |
| 骨組みの外形の左右の幅（左右の塔の外側から外側） | 32 cm |
| 下のフレーム（30×60、左右の塔の間） | 26 cm |
| 天板から上腕のアルミフレームの上面 | 左 26.4 cm、右 24.2 cm |

### 構成（説明と写真による）

- 左右の塔は30×120のフレーム1本で、中央の2つの溝の位置で下のフレームとつながる。
- 腕のモーターブロックは塔の外側の面に付き、前後は後ろから2つ目の溝の位置。
- カメラの柱は下のフレームの後ろ側に付き、下端は天板と同じ高さ。
- 柱の前の面に、上面を柱の上端にそろえて30×60のフレームが前へ伸び、その先にHeadYawの土台が付く。

### 写真から見積もった値・測っていない値

左右の塔の高さ（約32 cm）、柱の中心からpan軸までの前後の距離、30×60のフレームの長さは測っていない。pan軸の距離は写真から約9 cmと見積もり、モデルを見たユーザーの指摘で3 cm前の約12 cmにした。
左右の上腕の高さが2.2 cm違う原因（組み立ての差か測り方か）は確認していない。
腕の付け根の向き（`link_?1` のyaw）は測っておらず、モデルはAstraのURDFの値のまま。

## 2026-10-25 — 右腕の付け根の向き

### 対象・条件

右腕のトルクが入った状態で、ユーザーが腕は真横（外側）に伸びていると伝えた。そのときの関節角は肩（joint_r2）−0.0215 rad、肘（joint_r3）−1.546 radだった（`arm_node` 起動直後の読み）。

### 決定事項と根拠

まず、上腕が真横（base_link yaw −90°）を向くように、`frame_table_202610.yaml` の右腕の `yaw` を −1.7349（= −π/2 − 0.18555 + 0.0215、0.18555はjoint_r2の原点のyaw）にした。
同じ姿勢で、モデルの前腕は上腕から約9°時計回りに曲がった向き（−99°）になった。

その後、手先を手前の机の上（肩 0.571 rad、モデルの手先 (0.453, −0.202, 0.452)）へ動かすと、点群の手の点はモデルの手先より+y側（中心で約6 cm）に集まった。
RVizを見たユーザーが、モデルの肩の回りが実機より少ないと判断した。
肩から手先まで約0.42 mのため、6 cmを約0.14 radとして、`yaw` を −1.5949 にした（肩の読みのオフセットと区別しない）。
その後もユーザーがRVizでモデルの手が約3 cm右（−y）にずれていると判断し、さらに0.071 rad足して −1.5239 にした。
この値では、真横の姿勢の上腕は −77°、前腕は −87°になる。

その後、`arm_cloud_calibrate.py`（`--allow-frozen --keep-fingers`、肩と肘を推定）で、右腕の手先を机の上の5か所（手先の高さ0.452 m）に置いて点群を撮った。
腕の点が対応したのは2姿勢（対応した点80点・153点）で、他の3姿勢は0〜25点だった（視野に入るのは主に手先）。
推定は肩 −0.108 rad、肘 +0.158 radで、対応した2姿勢の残差は10.4 / 8.5 mmから7.1 / 5.9 mmに下がった（肩と肘の相関 −0.95）。
一度この値（`yaw` −1.6319、`joint_r3` 0.158）を入れたが、モデルの手の真下に、モデルの最下面より平均9〜14 mm低い点が多くあった。
腕全体の高さ（`shoulder_xyz` のz）も推定するようにツールを直し、同じ5姿勢を指の点も含めて計算し直した（撮影時のモデル `yaw` −1.5239、オフセットなしが基準）。
対応した点は161 / 172 / 511 / 569 / 43点、残差は4.1〜6.9 mm（5番目は9.4 mm）、推定は肩 +0.0005 rad、肘 +0.035 rad、高さ −0.020 m だった（相関は肩と肘 −0.76、高さとはほぼ0、1姿勢抜きの変化は最大0.005）。
これにより `shoulder_xyz` を [0.03, −0.232, 0.202]（メジャーでは0.222）、`yaw` を −1.5234、`joint_offsets` を `{joint_r3: 0.035}` にした。右腕の手先の固定高さは0.452 mから0.432 mになる。

### 確認していない範囲

上腕・前腕が真横だったこと、肩の回りが少ないことは目視で、角度は測っていない。
高さ2 cmの差の原因（肩の高さの測り方、前腕のたわみなど）は確認していない。新しい値で撮り直した残差は確認していない。
この日の2回のplaceは手先0.452 mのモデルで行ったため、実際に離した高さは計画（2〜4 cm）より約2 cm低かったと推定している。
点群には y < −0.21 の点がなく（視野の端と思われる）、手首側が見えていないので、0.14 radは手の点の中心からの見積もり。
肘の読みのずれと肩のオフセットは、1つの姿勢では区別できない。左腕の向きは確認していない。
`frame_calibrate.py` の手順は、関節角が更新されていなかったため成立しなかった（[motor.md](motor.md)）。
