# Macでの音声認識・発話の検証

Macのマイクとスピーカーで、DGX Spark / trailpcの音声認識（ASR）と発話（TTS）を試す。リポジトリ直下で実行する。
ROSのトピック・アクションは出さない。ROSから使う場合は[音声スタック](../../../../overlay_ws/src/aha_perception/docs/audio.md)を参照する。

```bash
bash tools/perception/macos/audio/interactive.sh
```

ブラウザで操作ページ（`http://127.0.0.1:8766/`）が開く。

## 発話だけを試す

```bash
bash tools/perception/macos/audio/speech.sh --user <Unixユーザー名>
```

ブラウザで発話のページ（`http://127.0.0.1:8767/`）が開く。マイクと音声認識は使わないので、マイクの許可は不要で、推論先のGPUも読み上げの分しか使わない。

1. 推論先を選び、「接続する」を押す。
2. 英語の文を入力するか例文を押し、声を選んで「読み上げる」を押す（Enterでも読み上げる）。何文目を読み上げているかが表示され、「止める」で途中で止められる。
3. 読み上げた文は下に新しい順で並び、「もう一度」で同じ声のまま再生できる。最初の音までの時間も表示する。
4. 使い終わったら「切断する」を押し、ターミナルでCtrl+Cを押す。

読み上げは英語のみである。上の音声のページと同時に開ける。

## 準備

- Mac: uv（0.7.11以上）。Pythonの依存は初回起動時に `.venv-audio-macos` へ導入する。
- 接続: [SAM 3.1検証ツール](../sam31/README.md#準備)と同じ。
- 実行するターミナルにマイクの使用を許可する（システム設定 → プライバシーとセキュリティ → マイク）。

## 操作

1. 推論先、聞き取る言語、ユーザー名、マイクを選び、「接続する」を押す。
   推論先でイメージをビルドしてコンテナを起動し、モデルを読み込む（初回は数十分、モデルは約6 GB）。
2. 接続すると「聞いています」と表示される。話すと、認識結果と話し終わりからの遅延が会話に並ぶ。
3. 下の欄に英語を入力してEnterを押すと、Macのスピーカーで読み上げる。読み上げ中はマイクを無視し、「止める」で途中で止められる。
4. 使い終わったら「切断する」を押す。推論先のコンテナと一時コードを削除し、モデルのキャッシュは残す。
5. ターミナルでCtrl+Cを押すとツールが終了する。接続中なら同じように片付ける。ブラウザのタブを閉じるだけでは切断しない。

接続中でも聞き取る言語を切り替えられる。ページを開き直しても、会話と接続は保持される。
聞き取る言語の「日本語（Qwen）」は比較用で、「日本語（Haas）」が標準である。
「聞き取りやすくする語」は日本語のモデルだけが使う。Haas では `Haas=ハース` のように読みを付ける。

| 表示 | 意味 |
| --- | --- |
| 聞いています | 発話を待っている |
| 話を聞き取っています | 発話を検出して録音している |
| 文字にしています | 推論先で認識している |
| 読み上げています | 読み上げ中。マイクは無視する |

入力レベルのバーが読み上げ以外でほとんど動かないときは、マイクの選択と許可を確認する。

## オプション

起動時の既定値を変える。全項目は `--help` を参照する。

| オプション | 用途 |
| --- | --- |
| `--target dgx\|trailpc` / `--language en\|ja\|ja-qwen` / `--user <Unixユーザー名>` | ページの初期値 |
| `--host <SSH接続先>` / `--port 0` | SSH configの別名を使う。ユーザー名は不要で、ポートもconfigに従う |
| `--identity-file <秘密鍵パス>` | 標準以外の鍵を指定 |
| `--output-device <名前か番号>` | スピーカーを指定 |
| `--capture-rate 48000` | マイクの録音レートを変える（既定16000） |
| `--ui-port <番号>` | ページのポートを変える（既定は音声8766、発話8767） |
| `--ui-port 8766` / `--no-open` | ページのポートを変える / ブラウザを開かない |

ページは `127.0.0.1` だけで待ち受ける。SmartTurnとSilero VADはMacのCPUで動かし、初回はSmartTurnの重みを取得する。
発話の区切り方は `SegmenterConfig` の既定値を使い、ROS側の `params.yaml` は読まない。
