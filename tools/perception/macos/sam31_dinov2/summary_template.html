SAM 3.1 は「缶」「ボトル」のような種類の言葉には強いが、「pringles」「キャンベル」のような商品名では 見た目の似た別の商品も拾う（2026-10-11、「pringles」でプリングルズ 0.84、キャンベル缶 0.74）。 商品名の物だけを見つけるために試した方式と、方式を選んだ経緯をまとめる。 使い方と再実行の方法は README.md、条件・結果・不明点の記録は 物体検出の検証記録、全写真の結果は python report.py で手元に作るレポートを参照する。

結論

SAM 3.1＋DINOv2（参照画像との見比べ）を選んだ。 キャンベル缶の27枚で、正解した写真が最も多く（23/27）、1枚 0.4 秒と案A（平均 28 秒）より約70倍速い。 検出では Qwen を使わず、裏向きの缶も参照画像の背面・側面と見比べて見つけられた。 SAM 3.1 に渡す種類の言葉は、登録のときに Qwen が参照画像を1回見て決める（固有名詞をそのまま渡すと候補から漏れる）。 Qwen を使わない場合は、種類の言葉を自分で指定する。 ただし、しきい値は同じ27枚で選んだ値で、撮影場所が変わると点数が下がる（下の「注意点」）。 使い方（参照画像の撮影 → 場面の撮影 → dino.py detect）は README.md にある。本体の sam31/interactive.py --vlm は案Aのまま。
